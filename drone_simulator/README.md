# Drone Simulator (3D Raycasting)

A lightweight drone simulator built in Python with a real-time 3D raycasting renderer.

## Features

- Real-time first-person 3D view generated with raycasting
- Drone movement with collision detection
- Adjustable altitude and yaw
- Live minimap with raycast sensor sweep
- HUD with position, altitude, heading, and FPS

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Controls

- `W / S`: move forward/backward
- `A / D`: strafe left/right
- `Q / E`: rotate yaw left/right
- `R / F`: increase/decrease altitude
- `ESC`: quit
